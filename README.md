# Poduim

Application web de gestion de tournois de baby-foot. Créez des tournois, ajoutez des équipes, générez automatiquement les matchs et suivez les résultats en temps réel.

## 📋 Table des matières

- [Demarrage rapide](#-demarrage-rapide)

## 🚀 Demarrage rapide

```bash
# 1. Cloner et configurer l'environnement
git clone <repository-url>
cd poduim
make setup

# 2. Installer les dépendances
make install

# 3. Lancer l'application (Docker)
make dev
```
